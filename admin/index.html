İki sitenin duyurularını buradan yönetirsin. Giriş için GitHub erişim anahtarın (token) gerekir.

Token nasıl alınır?
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → Enskygr234.github.io
  3. Permissions → Repository → Contents: Read and write
  4. Oluşan github_pat_… anahtarını buraya yapıştır.

Token yalnızca bu tarayıcıda saklanır ve sadece api.github.com'a gönderilir.
